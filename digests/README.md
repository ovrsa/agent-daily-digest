# Digests

LLM / Coding Agent デイリーダイジェストのアーカイブ。

毎朝ローカル Mac の launchd が `scripts/run-local.sh`（`python -m digest_pipeline`）を実行し、根拠付きの日本語ダイジェストを `YYYY-MM-DD.md` 形式でこのディレクトリに自動コミットする。各ダイジェストのコミットには、Judge のレビューがコメントとして付く。

採用に値する item が無い日はファイルを生成しない（＝歯抜けの日付がありうる）。
