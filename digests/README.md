# Digests

LLM / Coding Agent デイリーダイジェストのアーカイブ。

毎朝 claude.ai のリモート routine が `src/fetch.py` で 8 ソースを収集し、`prompts/system-prompt.md` の編集ルールに従って日本語ダイジェストを生成、`YYYY-MM-DD.md` 形式でこのディレクトリに自動コミットする。

採用に値する item が無い日はファイルを生成しない（＝歯抜けの日付がありうる）。
