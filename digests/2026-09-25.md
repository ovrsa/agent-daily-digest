# Agent / Coding Agent Daily Digest 2026-09-25

## Worth Knowing

### [Runway’s WorldPrompt and the Engineering of Real-Time Worlds](https://www.latent.space/p/runway)

ソース: latent_space / 著者: Richard MacManus / 公開: 2026-09-25

- 何をしたか／何が分かったか: Runway は GWM Worlds 2 の入力形式 WorldPrompt を、持続する世界文脈とタイムスタンプ付き行動列の2層で定義した。一次資料は、自由文の制御を十分に生かすには世界の状態を追跡し行動を即時生成する外部リアルタイムハーネスが必要になりうると述べている。
- 読む理由: 世界モデルを Agent のテスト環境に使う場合の制御面と、自己回帰生成の誤差蓄積、文脈の追い出しという長時間ループ共通の課題を、具体的な設計例で確認できる。
- 根拠: 共同CEOは自己回帰の最大の課題を、生成フレームを入力に戻すことで生じる誤差蓄積と述べた。エージェントに旗へ移動させるテストは、ロボットが赤・青の旗へ最初の試行で到達し、赤から青の順序指定にも成功したと Runway は述べている。
- 留保: GWM Worlds 2 は研究プレビューで、エージェントが読める構造化状態はなく観測のみ。旗到達テストは単純な場面の少数試行で、数値の測定条件は未確認。本文後半は未読。
